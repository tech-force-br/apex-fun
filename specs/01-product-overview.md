# 01 — Product overview

## What ApexFun is

ApexFun is a website that teaches Salesforce Apex to people who are not programmers.

Students read short theory, then type real Apex. The site runs the code and tells them if it is right. They do not create a Salesforce org.

The site name while we build is **ApexFun**.

## One-sentence goal

Teach Apex fundamentals with little theory and many small, checked exercises.

## v1 ships

- Accounts: email/password and Google
- English and Brazilian Portuguese
- The **Variables** module only (theory and exercises; the owner sets how many cards)
- A map that shows later modules as locked (“Coming later”)
- An admin screen for the site owner only
- A code runner that uses **aer** on a server (private use until licensed)

## v1 does not ship

- Paid walls or pricing
- Other teachers / multi-tenant schools
- Official Salesforce mascots
- Running code inside a Salesforce org
- Hints on each exercise
- Debug-match as a pass check
- Triggers as a module on the map

## What students do

1. Sign up and pick a language.
2. Open Variables on the map.
3. Read theory cards in order.
4. Type exercises in order. Each one must pass before the next card unlocks.
5. Finish mixed review.
6. See a results page. 90% clean first tries completes the module. Under 90% restarts Variables from the start.

## What the owner does

- Write theory and exercises in English and Portuguese
- Reorder cards inside a module
- Add topics or modules later
- View one student’s progress
